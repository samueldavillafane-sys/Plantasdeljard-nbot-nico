# Flora del Jardín Botánico IED La Victoria

Sitio web educativo sobre la flora tropical, biodiversidad y conservación local.

## Estructura

- `index.html` — página principal.
- `css/styles.css` — estilos y diseño responsive.
- `js/script.js` — tarjetas, imágenes, modal y trivia.
- `README.md` — información del proyecto.

## Publicarlo con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube `index.html`, la carpeta `css`, la carpeta `js` y este `README.md`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub genere el enlace de tu sitio.

El sitio utiliza algunas imágenes cargadas desde Wikimedia/Wikipedia mediante Internet, por lo que esas imágenes requieren conexión para aparecer.
